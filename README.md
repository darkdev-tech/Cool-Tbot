# Cool-Tbot

Cool-Tbot is a simple, modular Telegram bot built with Node.js and [Telegraf](https://telegraf.js.org/). It's designed for easy customization and feature expansion.

## Features

- Command-based structure
- Fast responses via Telegraf
- Easy to extend with new commands
- Environment-based configuration
